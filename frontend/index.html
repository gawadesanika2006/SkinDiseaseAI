About SkinNova AI & Mobile Architecture

Machine learning specs, mobile Expo camera integration, and safety boundaries.

🧠 Neural Architecture

SkinNova uses a ResNet-18 network fine-tuned on dermoscopy datasets, running INT8 dynamic quantization for minimal memory usage (<150 MB RAM) and sub-second inference speeds.

📱 Expo Camera & Mobile App Integration

SkinNova is available both as a standalone Progressive Web App (PWA) and as an Expo React Native mobile project using expo-camera for full device hardware camera permissions.

# Run with Expo React Native:
npx create-expo-app SkinNovaMobile
npx expo install expo-camera expo-image-manipulator
# Points to /predict API endpoint directly
⚖️
Clinical Screening Disclaimer

SkinNova AI is strictly an educational screening aid and does not constitute medical diagnosis, oncology clearance, or treatment advice. Consult a board-certified dermatologist for all concerning, changing, or bleeding lesions.

Install SkinNova AI

Verified Standalone Application

Install SkinNova AI onto your device home screen for fullscreen camera viewfinder, faster AI scanning, and offline encyclopedia access.

Mobile Manual Installation:
• iPhone / iPad (Safari): Tap Share ⎋ → Scroll down → Tap Add to Home Screen.
• Android (Chrome): Tap the three dots (⋮) menu → Tap Install app.
